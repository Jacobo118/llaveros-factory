# Imágenes de Llaveros Factory

Coloca aquí los archivos con **exactamente estos nombres** y aparecerán
automáticamente en la web (sustituyendo el placeholder gris con el icono).
Mientras el archivo no exista, se mostrará un bloque con el nombre, el uso y
el tamaño recomendado.

Formato recomendado: **WebP**, salvo el logo (SVG) y el favicon (ya incluido).

## Global (todas las páginas)

|---|---|---|
| `logo.svg` | Cabecera y pie de página | 200x200px (SVG vectorial) |
